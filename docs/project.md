# DCTimer-Android 项目现状

日期：`2026-09-09`

## 项目定位

`DCTimer-Android` 当前是基于原版 DCTimer 的蓝牙硬件计时增强版本，重点是把智能魔方和蓝牙计时器的真实硬件计时链路做稳。

当前硬件方向：

- 智能魔方：保障 `3x3` 蓝牙计时、打乱引导、自动起停表、成绩保存和解法重建。
- 蓝牙计时器：保障 `QiYi Smart Timer` 的准备、运行、停止、断开重连和异常恢复。
- 魔方机器人：作为可选执行设备，与智能魔方协同完成物理打乱和复原，不参与计时或成绩保存。

## 当前基线

- Android 工程：`AndroidX + AGP 8.9.2 + Gradle 8.11.1 + JDK 17`
- `compileSdk / targetSdk`：`35`
- 文件导入导出、打乱导入导出、背景图选择：`SAF / Uri`
- release 签名：`key.properties` 或 `-P` 参数注入

## 已接入硬件

- 智能魔方：`MoYu32`、`QiYi / Tornado V4 智能版`、`GAN v2 / v3 / v4`
- 蓝牙计时器：`QiYi Smart Timer`
- 魔方机器人：`GAN Robot`

## 当前能力

### 普通计时

- 背景图片支持单指拖动、双指缩放、重置和应用，选图后进入调整，也可重新调整当前图片，或清除当前背景恢复主题背景色（同时清空图片引用与取景设置，保留原图）；原图不变，仅保存主体位置和缩放倍数，取消不修改当前设置。预览叠加计时数字与打乱文字供取景参考，横竖屏按同一主体位置重新取景；大图降采样，Android 7.0 及以上读取 EXIF 方向。手势、横竖屏与不同图片来源待真机验证。

- 支持键盘操作：按住空格达到“启动延时”后显示绿色准备态，松开起表；计时中任意按键按下停表，Esc 取消本次计时且不保存成绩，保留当前打乱。
- WCA 观察和多段计时沿用触摸规则：首次空格操作进入观察，再次长按松开起表；多段计时按键逐段记录，最后一段停表。
- 长按重复事件不会重复触发；切页或窗口失去焦点会取消尚未完成的空格准备。手动输入与蓝牙设备模式保持各自的输入逻辑，外接键盘真机体验待验证。

### 智能魔方

- 已打通“按打乱进入 `READY` -> 首转起表 -> 还原停表 -> 自动保存成绩”的主流程。
- BLE 扫描按设备结果直列展示，连接阶段自动识别协议。
- 计时页和魔方状态弹窗已接入 `GLSurfaceView + OpenGL ES 2.0` 的 `3x3` 实时 3D 预览，支持基础层转动画、手动拖动视角、陀螺仪姿态跟随与姿态重置；MoYu32 陀螺仪姿态跟随已完成真机验证，GAN Gen2 / Gen4 已完成姿态协议接入和单元测试，真机验收待完成；GAN Gen3 未收到有效姿态时不会误判为支持；普通打乱图仍使用 Canvas / Bitmap。
- `QiYi / Tornado V4` 姿态已接入 `QiyiCubeProtocol`：识别解密后的 `0xCC 0x10` 固定 16 字节帧，校验 CRC16-Modbus，按大端有符号 `int16 / 1000` 解码并以 `(ax, ay, az, aw)` 轴顺序归一化；轴向已根据真机反馈修正，`XMD-TornadoV4-i` 与 `QY-QYSC` 分型号完整验收仍待验证。
- GAN v2 / v3 / v4 已接入实体重置协议；v2 / v3 已完成真机验证，v4 已由贡献者在 i4 / iC4 完成验证，其他型号和固件待验证。
- MoYu32 协议已接入 `0xA2 Set Cube State` 实体重置，覆盖使用同组 service / characteristic 的兼容设备；报文、加密链路和状态帧接收条件已完成单元验证，真机待验证。
- 打乱体验支持进度提示、偏离后的逆序纠错、超长纠错提示先复原，以及打乱完成后的 `READY` 等待首转。
- 打乱选择已新增 `3阶 CFOP` 与 `3阶 Roux` 专项训练分组，真实分类索引追加在末尾，展示顺序映射到普通 `3阶` 后面；`3阶 CFOP` 当前显示为 `F2L / OLL / PLL / 顶层 / CLL / ELL / COLL / EOCP / 2GLL / OLLCP / ZZLL / ZBLS / ZBLL`，`3阶 Roux` 当前包含 `CMLL / LSE / L10P`，真机流程待验证。
- `3阶 CFOP` 与 `3阶 Roux` 专项训练支持独立训练朝向，默认 `黄顶绿前`；训练状态、打乱提示和状态弹窗按训练朝向展示，内部仍保存物理状态和物理转动。
- 智能魔方专项训练支持阶段完成判定：`OLL` 完成 OLL 即停表，`F2L` 完成 F2L 即停表，`ZBLS` 完成 F2L + 顶层棱朝向即停表，`COLL` 与 `OLLCP` 完成顶层角块关系即停表，`EOCP` 完成顶层棱朝向 + 顶层角块相对顺序即停表，允许 U 层整体偏移，`CLL` 在 F2L 保持下完成顶层角块且只放开顶层棱块状态即停表，`CMLL` 完成 Roux CMLL 即停表，其余 CFOP 专项、`LSE` 与 `L10P` 仍要求完整复原；该能力已通过单元与编译验证，真机待验证。
- 设置页已新增 `智能` 分类，支持训练朝向、使用解法、打乱推进显示样式、默认布局虚拟魔方大小和陀螺仪跟随视角开关。新增默认开启的“打乱时自动校准姿态”，确认打乱完成时同步校准预览与重建基准，真机待验证。
- 设置页 `界面` 分类支持手动切换应用语言，可选择跟随系统、英文、简体中文或繁体中文。
- 设置页 `界面 - 导航栏位置` 支持顶部（默认）和底部，切换立即生效并保存；底部模式仅将“计时 / 成绩 / 设置”移入独立底栏，增加文字标签并沿用当前背景色，项目打乱选择器移入顶部中间，抽屉、蓝牙和更多入口保持在顶部。横竖屏、背景图和计时隐藏/恢复效果待真机验证。
- 智能魔方计时页支持默认模式与大屏“魔方居中布局”，可在“智能 - 布局”中切换；魔方居中布局仅在大屏设备上生效。
- `WCA` 观察模式下，打乱完成后进入观察，首次真实转动起表。

### 解法重建与统计

- 成绩详情阶段表改为阶段、观察(s)、执行(s)、步数、TPS 五列；窄屏、放大字体或长数值可横向滑动。观察包含上一阶段结束到首个非 U 层动作的间隔，以及阶段开头的 U / U′ / U2 调整和转体，执行为剩余时间；执行开始后的 U 层动作仍计入执行，TPS 继续按阶段总用时计算。F2L 汇总累加各子阶段，旧成绩缺少拆分数据时两列显示“—”。布局和时间口径待真机验证。

- 智能魔方成绩将重建展示文本保存到 `moves`，并可追加可空 `solve_meta`；陀螺仪样本仅用于当次解法重建，不持久化、不提供回放。
- 已支持智能魔方解法重建类型选择：`333-smart-cf4op` 分段为 `Cross / F2L 1-4 / OLL / PLL`，`333-smart-roux` 分段为 `FB / SB / CMLL / L6E`。
- 解法重建参考 cuberoot 的相对记号方案：识别观察阶段和计时中的转体，并同步后续步骤朝向；结合核心姿态识别 `E / M / S` 与双层转动。无陀螺仪时按十字底色选择上下，正面固定选取一个方向。新重建链路已通过单元与编译验证，真机待验证（含 Roux）。
- 已移除“解法朝向基准”设置。废步通过状态回环和同层过转识别，以括号保留展示；废步仍计入实际 STM，转体不计步。
- `AUF` 默认并入 `PLL`；`U2` 与 `E / M / S` 按一步计，`x / y / z` 不计入主 TPS。
- 成绩列表支持默认“最新在下”和可选“最新在上”，该时间方向应用于全部分组；成绩、平均和历史 `PB` 排序仅作为当前分组临时排序。

### 蓝牙计时器

- `enterTime` 已拆成“智能魔方 / 蓝牙计时器”两条独立硬件入口。
- 计时主页顶部蓝牙入口可同时扫描智能魔方和蓝牙计时器；服务识别成功后才切换到对应的计时与成绩链路，待真机验证。
- `QiYi Smart Timer` 已按独立协议接入。
- 设备语义：准备态只显示待起表，运行态由本地时钟刷新，停表后以设备成绩保存。
- 蓝牙计时器模式不启用应用内 `WCA` 观察和观察提示。
- `READY / RUNNING / STOPPED` 主链、断开、重连与异常恢复已完成真机验证。

### 魔方机器人

- `GAN Robot` 从抽屉的独立页面进入，支持扫描、连接、断开、手动执行公式、根据智能魔方状态复原，以及实体按钮触发打乱或复原。
- Robot 可与智能魔方同时连接：智能魔方提供当前物理状态和当前打乱目标，Robot 只负责执行物理转动；Robot 动作不进入 `enterTime`、计时状态机、成绩保存或解法统计。
- 该能力已由贡献者提供真机演示与测试说明，维护者暂无设备复测；协议仍有未确认细节，详见 `docs/others/gan-robot.md`。
