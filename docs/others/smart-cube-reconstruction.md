# 智能魔方相对步骤重建

## 范围与参考

参考本地 `cuberoot/cuberoot.me/core/packages/shared/src/timer/reconstruct/` 的 `orient.ts`、`rotation_detect.ts`、`core_track.ts`、`humanize.ts`、`error_detect.ts`、`recon_text.ts`。Android 实现保留现有 CFOP / Roux 分段与成绩保存入口，按同样的核心思路实现相对记号，未移植参考项目的回放、编辑器或完整分析界面。

## 数据流

1. 协议层继续上报物理转层与归一化四元数。重建记录不受“陀螺仪跟随视角”开关控制。
2. `SmartCubeGyroRecorder` 在打乱完成（包括手动跳过打乱）后记录观察和计时阶段姿态。首个连接样本建立传感器基准，预览的手动拖动与姿态重置不改变重建基准。
3. 首次转层为计时零点。姿态接收时刻按相邻转层接收时刻插值到设备时间线；观察样本使用负时间。成绩仍使用设备转层间隔，不以姿态时间替代。
4. 结束时生成重建文本及既有 `solve_meta` 内的派生统计，随即释放样本。尝试重置清空记录，连接切换清空传感器基准；四元数与接收时刻均为 `transient`，不导出、不持久化。
5. 记录上限为 100 Hz、60000 个样本；超过上限时整次退回无姿态重建，避免用截断轨迹推导错误朝向。

## 识别规则

- **朝向与转体**：在 24 种正交姿态中匹配，初始容差 45°、后续容差 35°；未达到阈值的手抖不产生记号。跳过中间姿态的事件拆成最短转体路径。观察转体单列为 `Inspection`，计时中转体更新后续面记号。
- **中层**：对相邻逆向对层组合进行分段内动态规划，选择不重叠且隐含朝向在段末闭合的组合。可用核心姿态证据补充非闭合组合；有姿态时首段中层候选要求证据。核心事件匹配容差为 250ms，半转证据可支持两对四分之一转。中层不跨阶段合并；两个编码器步骤之间出现独立转体时，也保留为分开的转层，避免丢失转体及后续朝向。
- **双层**：核心转动加同轴反侧外层补偿，匹配容差 120ms。先保留中层证据，剩余姿态再用于双层识别；双层消费核心事件，避免重复显示换握转体。同层两次短间隔四分之一转可识别成半转。
- **无姿态**：比较六个底色最早完成 F2L 的位置，再比较最早十字；平局优先 D。底色确定后其余四个正面固定取一个，不推断真实握法。不再读取旧 `scori` 偏好。
- **废步**：记录原始转层后的状态，回到最近出现的相同状态即标记区间；重复区间按转层去重。同层过转也保留标注。废步用括号包裹，不直接删去或抵消；状态回环统计原始转层数和时间，同层过转不把整段时间计入浪费。
- **计数**：外层、中层、双层半转均按一个 STM 计；废步计入实际步数，`x / y / z` 和观察阶段不计入 STM / TPS。

## 验证与限制

单元测试覆盖姿态离散化、后续步骤换面、观察转体、中层/双层及其半转拆分上报、阶段边界、无姿态闭合组合、状态回环、过转、抖动、时间映射与记录清理。独立贴纸几何测试验证重建记号执行结果与原始转层在测得朝向下等价。

新重建链路真机**待验证**。BLE 姿态与转层没有统一设备时间戳，因此接收时刻插值仍会受丢包、批量补发和传输延迟影响；未收到或无法匹配的姿态不臆测转体，保留可解释的转层。首个连接姿态作为传感器基准，不宣称恢复现实空间中的绝对朝向。当前未实现参考项目针对各品牌历史录制格式的兼容及漂移后的局部闭环恢复。

真机验收应分别使用 MoYu32、支持姿态的 GAN 和 QiYi / Tornado V4：

- 打乱完成后做 `x / y / z` 观察转体，检查 `Inspection` 与起手步骤朝向。
- 计时中换握后继续转层，检查后续步骤；关闭 3D 跟随后重复。
- 对照执行 `M / E / S`、`r / u / f` 及对应逆转、半转，确认不重复插入核心转体。
- 做往返废步和同层过转，确认括号、实际步数和阶段耗时。
- 连续两次计时、手动跳过打乱、重置魔方、断开重连，确认记录不串到下一次。
- 无姿态设备检查不同十字底色；旧成绩应继续正常展示。
