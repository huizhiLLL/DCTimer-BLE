# MoYu32 智能魔方重置协议

更新日期：2026-09-09

## 范围

使用 MoYu32 service `0783b03e-7735-b5a0-1760-a305d2795cb0` 及对应读写特征的设备，通过 `0xA2 Set Cube State` 同步实体魔方内部维护的逻辑状态。当前以 WeiLong V10 AI 的公开协议和真机验证结果为参考，其他兼容型号仍需真机验证。

业务层先把 App 内状态重置为完成态，再通过 `Moyu32CubeProtocol.onLocalCubeReset()` 发送协议请求。协议层只写入固定完成态，不提供任意 facelet 状态写回。

## 报文

加密前的固定 20 字节请求为：

```text
A20000002492494924926DB6DB924924B6DB6D00
```

- `0xA2` 表示设置魔方状态。
- 中间 144 bit 使用与 `0xA3` 状态帧相同的 `FBUDLR` 面块编码。
- 最后一字节未用于设置状态。
- 请求继续使用 MoYu32 现有的 MAC 派生密钥加密链路。

设备收到请求后会返回 `0xA3` 状态帧。协议层在等待重置确认时允许重新接收该状态帧，并使用其中的 move counter 更新计步基线；如果确认前已经收到真实转动，则保留原计步基线继续处理，避免进入持续丢步状态。
